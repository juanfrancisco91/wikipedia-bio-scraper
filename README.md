# Automatizacion de Extraccion de Datos Biograficos de Personajes desde la pagina de Wikipedia.

## Tecnologias
- Lenguaje python
- Webscrapping BeatifulSoup4
- Requests para la solicitud a la pagina
- os para informacion del sistema

### Como Usar?

El script es muy intuitivo, luego de ejecutar pip install -r requeriments.txt para obtener todas las bibliotecas
necesarias para el buen funcionamiento de este.

Le puedes ingresar todos los links que desees y cuando no tengas mas simplemente le precionas el numero 0 y el programa
si todo sale bien te devolvera un archivo .csv con la informacion dividida por columnas, las variables son las siguientes:

Nacimiento

Fallecimiento

Causa de Muerte

En un futuro se ira trabjando para poder agregar mas datos.
